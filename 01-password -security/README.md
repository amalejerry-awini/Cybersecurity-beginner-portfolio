# Password Security Awareness

## Objective

The purpose of this project is to understand the importance of strong passwords and good account-security practices.

## What Makes a Strong Password?

A strong password should be difficult for attackers to guess. Good password practices include:

- Using long passwords or passphrases.
- Avoiding easily guessed personal information.
- Avoiding password reuse across different accounts.
- Using a password manager where appropriate.
- Enabling multi-factor authentication (MFA).

## Why Password Reuse Is Dangerous

Using the same password on multiple websites creates additional risk. If one service suffers a data breach and a password is exposed, attackers may attempt to use the same credentials on other services.

## Multi-Factor Authentication

MFA provides an additional layer of protection beyond a password.

For example, an account may require:

1. A password.
2. A verification code or authentication-app approval.

Even if a password is compromised, MFA can make unauthorized access more difficult.
