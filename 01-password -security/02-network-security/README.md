# Network Security Fundamentals

## Objective

This project documents my beginner-level understanding of networking concepts that are important in cybersecurity.

## IP Address

An IP address identifies a device or network interface on a network and allows devices to communicate with each other.

## Ports

Ports help identify network services running on a device.

For example, different services can use different port numbers to communicate.

## TCP and UDP

TCP and UDP are transport-layer protocols.

TCP focuses on reliable communication, while UDP generally prioritizes speed and lower overhead.

## DNS

The Domain Name System (DNS) helps translate domain names into IP addresses.

For example:

example.com → IP address

This allows users to access websites using domain names instead of remembering numerical IP addresses.

## HTTP and HTTPS

HTTP is a protocol used for communication between web clients and servers.

HTTPS provides encrypted communication using TLS, helping protect information transmitted between the user and website.

## Cybersecurity Importance

Understanding networking is important for cybersecurity because security professionals need to understand how devices, networks, protocols, and services communicate.
